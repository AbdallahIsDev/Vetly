Booking Engine — Button Visual Reference

What every button looks like, what it does, when it shows, and who stands next to it. Reference only — all clicks are dead.

The 3 shared style sets

Primary ButtonsAccent fill · padding 10px 22px · Continue, Book Now, Book another*, Try again, loading
Secondary ButtonsTransparent · 1px Border · padding 10px 18px · Back, Cancel, Done*, Reschedule*
Calendar LinksAdd to CalendarTransparent · Accent text + border · .ics, Google, Outlook

*Book another keeps tighter 10px 18px padding · Done and Reschedule render muted secondary text. Per-button groups are Text-only — labels editable, surfaces shared.

Navigation

Continue

Submits the current step's form and advances one step.

Shows on every step except the last (and except while submitting, when it becomes the loading state below).

Default
Hover / Pressed
Loading
In step — middle form step: Back far left, Continue far right

Book Now

Submits the booking to Cal.com.

Shows on the last step only (usually the calendar), in place of Continue.

Default
Loading
In step — calendar (last) step: Back far left, Book Now far right

Back

Goes one step back; entered values are kept.

Shows on every step except the first. Disabled (dimmed) while submitting.

Default
Hover / Pressed

Cancel + Booking… (submitting)

Cancel aborts the in-flight booking request and returns to the form.

Both appear only while the request is in flight: Back dims, Cancel joins the primary side, Continue/Book Now turns into the Booking… loader.

In step — submitting: dimmed Back left; Cancel + Booking… right

Failure screen (full)

Shows the booking failure: mark, title, subtitle, message card, then the retry action.
