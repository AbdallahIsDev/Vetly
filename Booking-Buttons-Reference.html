Booking Engine — Button Visual Reference

What every button looks like, what it does, when it shows, and who stands next to it. Reference only — all clicks are dead.

The 3 shared style sets + Button Texts

Primary ButtonsAccent fill · 10px 22px · Continue, Book Now, Book another*, Try again, loading
Secondary ButtonsTransparent · 1px Border · 10px 18px · Back, Cancel, merged calendar trigger*, Manage*
Calendar LinksOwns the dropdown menu panel (surface, border, rows) — no standalone button wears it anymore.

Button Texts holds 3 editable rows: Next Step (“Continue”) · Back Step (“Back”) · Final Action (“Book Now”). Cancel, Try again, and every other label are hard-coded constants. *Book another keeps 10px 18px · merged trigger + Manage render muted secondary text.

Navigation

Continue

Submits the current step's form and advances one step.

Shows on every step except the last (while submitting it becomes the Booking… loader).

Default
Hover / Pressed
Loading
In step — middle form step: Back far left, Continue far right

Book Now

Submits the booking to Cal.com.

Shows on the last step only (usually the calendar), in place of Continue.

Default
Loading
In step — calendar (last) step: Back far left, Book Now far right

Back

Goes one step back; entered values are kept.

Shows on every step except the first. Dimmed while submitting.

Default
Hover / Pressed
Disabled (while submitting)
In step — first form step has no Back: Continue stands alone, right

Cancel + Booking… (submitting)

Cancel aborts the in-flight booking request and returns to the form.

Both appear only while the request is in flight: Back dims, Cancel joins the primary side, Continue/Book Now turns into the Booking… loader.

In step — submitting: dimmed Back left; Cancel + Booking… right

Removed
