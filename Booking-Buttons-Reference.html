Booking Engine — Button Visual Reference

Standalone visual catalog of every visitor-facing button/action in Code-Components/BookingEngine.tsx, rendered with current production defaults. Reference only: all clicks are dead, no booking flow, no API calls.

How to read: 10 actions own a Buttons Property-Control group (label + style fully author-configurable, untouched = exactly what you see here). 3 actions are hardcoded (no Buttons group; see notes per card). Hover/Pressed are unconfigured deltas by default, so they look identical to Default — the .15s ease-out transition is still armed on all six animated props. Disabled/loading appear only while the booking POST is in flight (isSubmitting).

Navigation (footer)

Sticky footer row: flex, gap 8, margin-top 24, sticky bottom 0, padding-top 12. Split default — Back far left, primary far right (space-between; single button: flex-end). Render order follows the Order control (Back-first default).
