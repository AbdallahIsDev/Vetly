Booking Engine — Button Visual Reference

What every button looks like, what it does, when it shows, and who stands next to it. Reference only — all clicks are dead.

The 3 shared style sets

Primary ButtonsAccent fill · padding 10px 22px · Continue, Book Now, Book another*, Try again, loading
Secondary ButtonsTransparent · 1px Border · padding 10px 18px · Back, Cancel, Manage
Calendar LinksAdd to CalendarTransparent · Accent text + border · .ics, Google, Office, Outlook

*Book another keeps tighter 10px 18px padding · Manage renders muted secondary text. One Button Texts submenu edits Continue / Back / Final Action / Cancel / Retry — every other label is a hard-coded constant.

Navigation

Continue

Submits the current step's form and advances one step.

Shows on every step except the last (and except while submitting, when it becomes the loading state below). Text editable in Buttons > Button Texts.

Default
Hover / Pressed
Loading
In step — middle form step: Back far left, Continue far right

Book Now

Submits the booking to Cal.com.

Shows on the last step only (usually the calendar), in place of Continue. Text editable in Button Texts (row “Final Action”).

Default
Loading
In step — calendar (last) step: Back far left, Book Now far right

Back

Goes one step back; entered values are kept.

Shows on every step except the first. Disabled (dimmed) while submitting. Text editable in Button Texts.

Default
Hover / Pressed
Disabled (while submitting)
In step — first form step has no Back: Continue stands alone, right

Cancel + Booking… (submitting)

Cancel aborts the in-flight booking request and returns to the form.

Both appear only while the request is in flight: Back dims, Cancel joins the primary side, Continue/Book Now turns into the Booking… loader. Cancel text editable in Button Texts; “Booking…” is internal.

In step — submitting: dimmed Back left; Cancel + Booking… right

Book another

Success screen, far right — the row's primary action. Label is a hard-coded constant (“Book another”).

Add to Calendar — one button + dropdown

Opens a styled dropdown: Google Calendar / Microsoft Office / Microsoft Outlook deep-link to their calendars; “Other” downloads the generic “Booking Appointment.ics” file.

Success screen, only when a booked time exists. Trigger label is a hard-coded constant; menu item labels are fixed provider names. Keyboard: Enter/Space opens, arrows move, Escape closes and returns focus to the trigger; outside press closes.

Google Calendar Microsoft Office Microsoft Outlook Other
Trigger + open menu (static replica — icons 20×20, surface token fill, Calendar Links border)

Manage

Opens the Cal.com manage link for this booking (reschedule or cancel happens there).

Success screen, only when Cal.com returned a manage URL. Short label (renamed from “Reschedule or cancel”); text editable in Copy (“Manage Link”).

Failure screen (full)

Shows the booking failure: mark, title, subtitle, message card, then the retry action.

Replaces the whole flow on booking failure. Content follows Content Alignment (Left default — shown); the action row stays centered on its own.
